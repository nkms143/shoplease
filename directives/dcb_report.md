# DCB Report Generation Directive

## Goal
Generate Demand Collection Balance (DCB) reports showing rent arrears and penalty demands for all shops within a specified financial year.

## Input
- Financial year (April to March)
- Report format (Print/Excel/CSV)
- Optional: Specific shops or "All shops"

## Tools/Scripts toUse
- `js/core/reports.js` → `generateDCBData()`, `formatReportRow()`
- `ReportModule.printDCB()` in `extra_modules.js` → Main report generation
- `Store.calculateOutstandingDues()` → Dues calculation per shop

## Financial Year Structure
- **Start**: April 1st of year Y
- **End**: March 31st of year Y+1
- **Example**: FY 2024-25 = April 1, 2024 to March 31, 2025

## Report Columns

| Column | Description | Calculation |
|--------|-------------|-------------|
| S.No | Serial number | Auto-increment |
| Shop No | Shop/Unit number | From applicant data |
| Name of Occupant | Tenant name | From applicant data |
| Monthly Rent | Base rent + GST | rentBase + (rentBase × 0.18) |
| Opening Balance | Arrears from previous FY | Historical calculation |
| Current Demand | Rent for current FY | Monthly rent × 12 |
| Total Demand | Opening + Current | Sum of above |
| Collection | Payments made in FY | Sum of payments |
| Balance | Outstanding amount | Total - Collection |
| **Arrear Demand (Penalty)** | **Penalty for late payments** | **Use penalty_calculation.md** |

## Arrear Demand (Penalty) Calculation

**CRITICAL**: This must use the same strict penalty logic as defined in `directives/penalty_calculation.md`.

For each unpaid month in the period:

```javascript
// For each month from opening period to end of FY
for (let month = openingDate; month <= fyEnd; month++) {
    if (!isPaid(month)) {
        const dueDate = new Date(month.year, month.month - 1, paymentDay);
        const penaltyParams = Store.getPenaltyParams(dueDate);
        const rate = penaltyParams.rate;
        const mode = penaltyParams.mode;
        
        const diffDays = Math.ceil((reportDate - dueDate) / (1000 * 60 * 60 * 24));
        
        if (mode === 'MONTHLY') {
            const months = Math.max(1, Math.ceil(diffDays / 30)); // STRICT POLICY
            penalty += months * rate;
        } else {
            penalty += diffDays * rate;
        }
        
        // Check for waiver
        if (hasWaiver(shopNo, monthStr)) {
            penalty = 0;
        }
    }
}
```

## Workflow

### 1. Report Parameters Selection
User selects:
- **Financial Year**: Dropdown (e.g., "2024-25")
- **Report Type**: Print/Excel/CSV
- **Shop Filter**: All or specific shops

### 2. Data Collection
For each shop:
```javascript
const applicants = Store.getApplicants();
const payments = Store.getPayments();
const waivers = Store.getWaivers();
const fyStart = new Date(year, 3, 1); // April 1st
const fyEnd = new Date(year + 1, 2, 31); // March 31st
```

### 3. Opening Balance Calculation
Arrears from before the FY start date:
```javascript
const openingDues = Store.calculateOutstandingDues(applicant, fyStart);
const openingBalance = openingDues.totalAmount;
```

### 4. Current Year Demand
Total rent for the financial year (12 months):
```javascript
const monthlyRent = applicant.rentBase + (applicant.rentBase  * 0.18);
const currentDemand = monthlyRent * 12;
```

### 5. Collection Calculation
Sum all payments made during the FY:
```javascript
const paymentsInFY = payments.filter(p => {
    const pDate = new Date(p.paymentDate);
    return pDate >= fyStart && pDate <= fyEnd && p.shopNo === applicant.shopNo;
});

const collection = paymentsInFY.reduce((sum, p) => sum + p.total, 0);
```

### 6. Balance & Penalty
```javascript
const totalDemand = openingBalance + currentDemand;
const balance = totalDemand - collection;
const penalty = calculateArrearPenalty(applicant, fyStart, fyEnd);
```

### 7. Report Generation

**Print Format** (HTML):
- Formatted table with proper alignment
- Headers and footers
- Print-friendly CSS
- Timestamp and generated by info

**Excel Format**:
- CSV export with proper formatting
- Headers in first row
- Data in subsequent rows
- Totals row at bottom

### 8. Report Output
Display/download generated report with:
- Report title with FY
- Generation timestamp
- Total summary (All shops):
  - Total Opening Balance
  - Total Current Demand
  - Total Collection
  - Total Balance
  - Total Arrear Penalty

## Validation Rules

1. **Financial Year**: Must be valid (not future)
2. **Date Range**: FY must have start and end dates
3. **Shop Data**: All shops must have valid rent information
4. **Penalty Calculation**: Must match other modules

## Edge Cases

### Mid-Year Tenant Changes
If tenant changed during FY:
- Split opening balance between old and new tenant
- Current demand prorated based on occupancy period
- Note transition in remarks

### Zero Rent Shops (Commercial vs. Residential)
- Include in report with ₹0 amounts
- Note status in remarks column

### Waived Penalties
- Show calculated penalty in parentheses
- Mark as "Waived" in remarks
- Don't include in total arrear demand

### Partial Year Occupancy
If shop became active mid-year:
- Opening balance = 0
- Current demand = prorated for active months only
- Penalty calculated from start date

## Common Pitfalls

1. ❌ Using wrong penalty calculation (Math.floor instead of ceil)
2. ❌ Not handling waived penalties
3. ❌ Incorrect FY date range
4. ❌ Missing mid-year tenant transitions
5. ❌ Forgetting to include GST in monthly rent
